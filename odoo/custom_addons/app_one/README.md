 # Odoo Real Estate Module

## Overview
This module provides comprehensive real estate property management functionality for Odoo 17. It allows users to manage properties, track offers, schedule visits, and handle the complete property sales cycle.

## Features
- Property management (create, edit, archive properties)
- Property types and tags for better organization
- Property offer management with acceptance/refusal workflow
- Property status tracking (New, Offer Received, Offer Accepted, Sold, Canceled)
- Automated selling price calculations
- Property search and filtering capabilities
- Reporting and analytics for real estate operations

## Installation
1. Clone this repository to your Odoo addons folder
2. Update your Odoo addons path if needed
3. Install the module from the Odoo Apps menu

## Configuration
After installation, you can configure the module settings under:
Settings > Real Estate > Configuration

## Usage
Navigate to the Real Estate menu to start managing properties:
- Create new property listings with detailed information
- Organize properties by type and tags
- Manage and respond to offers
- Track property status through the sales cycle

## Dependencies
- Odoo 17.0
- Base module
